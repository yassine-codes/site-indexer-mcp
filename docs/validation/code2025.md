## What this run validated (generic lessons)

- **Dynamic sitemaps** (generated by a server from a base-URL env var) work, and the host-mismatch check
  catches a sitemap built for a different domain than the property. This is a common mistake with any
  framework that takes a `SITE_URL` / `PUBLIC_URL` / `site:` setting.
- **Self-hosted Node + nginx apps** work with FILE verification through the framework's static dir
  (`public/` → `dist/`), as long as the server returns a real 404 for unknown files and not the SPA shell.
  The pre-flight check reports SPA fallbacks explicitly.
